# kasra*game — ماجرای اعداد اول | دستیار

بازی آموزشی فارسی برای یادگیری اعداد اول و مرکب و روش غربال اراتستن، مناسب ریاضی پایه هشتم.

## اجرا
فایل `index.html` را در مرورگر باز کن.

## ویدئوی آموزشی
برای پخش ویدئو، فایل را در مسیر `videos/prime-sieve-video.mp4` قرار بده. اگر پوشهٔ `videos` هنوز در مخزن نیست، ویدئو باید جداگانه به همین مسیر اضافه شود.

## انتشار با GitHub Pages
در تنظیمات مخزن، به **Settings → Pages** برو و منبع انتشار را روی شاخهٔ `main` و پوشهٔ `/(root)` قرار بده.
